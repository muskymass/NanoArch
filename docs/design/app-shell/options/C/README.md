# الاتجاه C: «لوحة القيادة» (Command Console)

**الفكرة:** منصة عمل للمحترفين على طراز بيئات التطوير: شريط أنشطة بالمجموعات الست، وشجرة تبويبات للمجموعة، وتبويبات مستندات مفتوحة، ولوحة سفلية (المشاكل / ملخص التكلفة / السجل)، وشريط حالة، ولوحة أوامر `Ctrl+K` تصل لأي من الأقسام العشرين بالكتابة. داكن أولاً، زوايا حادة (2–4px)، فواصل صفوف بدل البطاقات.

**لوحة المزاج (داكن، الافتراضي):** الخلفية `#0d0f11`، السطح `#14171a`، النص `#e3e7ea`، التمييز نعناعي `#22c388` (شريط الحالة يحمله). الفاتح: رمادي بارد `#e8ebee`. خيارات التمييز: نعناعي، كهرماني، سماوي، مرجاني، ليموني.

**الخطوط:** Segoe UI Variable Text للنص، وCascadia Mono/Consolas للأرقام والمراجع. بديل مضمَّن اختياري: IBM Plex Sans Arabic + IBM Plex Mono (SIL OFL 1.1)، نحو 150–250 كيلوبايت للوزن (تقدير لم يُقَس).

**التنقل (معرّفات `data-tab` ثابتة):** شريط الأنشطة = المجموعات (المدخلات، المخطط، الامتثال، الهندسة، الكميات والتكلفة، المخرجات)؛ الشجرة تعرض تبويبات المجموعة النشطة مرقّمة؛ كل تبويب يُفتح كمستند في الشريط العلوي (حتى 6)؛ و`Ctrl+K` للبحث السريع. المدخلات السريعة عمود قابل للسحب (220–460px)، والخصائص شريط تحت لوحة الرسم؛ والشجرة واللوحة السفلية قابلتان للطي. على الهاتف: شريط الأنشطة + لوحة الأوامر بديلاً عن الشجرة.

**التخصيص:** لغة، وضع، لون تمييز، كثافة (الافتراضي مضغوط)، حجم خط؛ تُحفظ وتُستعاد؛ وتبديل الوضع/اللغة من شريط الحالة ومن لوحة الأوامر.

**يصلح لمن:** المستخدم المتمرس الذي يبدّل بين الامتثال والكميات والمخطط عشرات المرات في الجلسة ويفضّل لوحة المفاتيح.

**كلفة التنفيذ: عالية.** أكثر الاتجاهات إضافةً: لوحة الأوامر، ومصفوفة المستندات المفتوحة، واللوحة السفلية (مصدر المشاكل من نتائج `cp`)، وإعادة كتابة الصدفة. تبقى `.tab` و`data-tab`، لكن حالة «المستند المفتوح» جديدة وتحتاج اختباراً مع `layoutApply` والحفظ/التراجع.

**المخاطر:** منحنى تعلم للمالك غير المختص؛ كثافة عالية بالنص الصغير (.875rem) تحتاج «مريح» وحجم خط أكبر لضعاف البصر؛ التمييز الافتراضي النعناعي قريب من لون «مطابق» الدلالي فيُنصح بسماوي إن تداخل المعنيان؛ الأرقام باللاتينية.

**ملاحظات:** بيانات عيّنة مُعلَّمة؛ أيقونات مرسومة أصلاً؛ الاختصار `Ctrl+K` يُضاف إلى مساعدة الاختصارات في التطبيق.
