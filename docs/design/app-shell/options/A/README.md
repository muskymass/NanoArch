# الاتجاه A: «مخطط أزرق» (Blueprint Studio)

**الفكرة:** غرفة رسم هندسية دقيقة. شريط جانبي بمجموعات يستوعب التبويبات العشرين، وخطوط رفيعة بدل الظلال، وكثافة مضغوطة افتراضياً، وأزرق مخطط مأخوذ من أيقونة التطبيق. يبقى النموذج الذهني الحالي: مدخلات | لوحة رسم | خصائص، لكن بأعمدة قابلة للطي وتغيير العرض.

**لوحة المزاج (فاتح):** الخلفية `#eef2f7`، السطح `#ffffff`، النص `#0e1b2a`، التمييز الافتراضي أزرق `#1564be`. الداكن: أردوازي أزرق `#0a1522`. خيارات التمييز: أزرق، فيروزي، كهرماني، وردي، أخضر (محسوبة لتجتاز AA في الأوضاع الثلاثة).

**الخطوط:** Segoe UI Variable Text ثم Segoe UI (تدعم العربية)، وأرقام Cascadia Mono/Consolas. بديل مضمَّن اختياري: IBM Plex Sans Arabic (SIL OFL 1.1)، نحو 150–250 كيلوبايت للوزن الواحد (تقدير لم يُقَس). المعاينة تعمل بخطوط النظام وحدها.

**التنقل (التبويبات العشرون في 6 مجموعات، معرّفات `data-tab` نفسها):**
| المجموعة | التبويبات |
|---|---|
| المدخلات | notes، sbc |
| المخطط | sketch، ol، bim، pr |
| الامتثال | rules، ov، cp، lib |
| الهندسة | str، mep، mx، an |
| الكميات والتكلفة | qto، boq، sched، ex |
| المخرجات | vr، dv |

مكان العناصر: الشريط الجانبي (يطوى إلى شريط أيقونات 58px) ← يحمل التبويبات. المدخلات السريعة عمود أول قابل للسحب (240–480px) وللإخفاء. لوحة الرسم في الوسط مع شريط البدائل. الخصائص عمود أخير قابل للسحب وللإخفاء. قائمة الملف/تعديل الحالية تنتقل إلى الشريط العلوي أو إلى مفتاح «القائمة».

**التخصيص:** لغة، وضع (فاتح/داكن/عالي التباين/النظام)، لون تمييز، كثافة، حجم خط؛ تُحفظ في ملف تفضيلات صغير تكتبه الصدفة (لأن `localStorage` مغلق في صفحة `with_html`) وتُستعاد.

**يصلح لمن:** المهندس المعماري وجلسات العمل الطويلة على شاشة واسعة؛ من يريد كل شيء على بعد نقرة.

**كلفة التنفيذ في `index.html` الحالي: متوسطة.** أقل الاتجاهات خطراً: `.tabs` تتحول إلى شريط جانبي دون تغيير `.tab` و`data-tab` ومعالجات النقر، والأعمدة الثلاثة موجودة أصلاً. العمل: إعادة كتابة CSS الصدفة (~150 سطراً الحالية)، نقل أزرار التبويبات إلى `<aside>`، ومقابض سحب (نحو 40 سطر JS)، ورموز تصميم بدل الألوان المبعثرة.

**المخاطر:** الكثافة المضغوطة قد تبدو «تقنية» لمالك غير مختص (التبديل إلى «مريح» يخفف ذلك)؛ 20 عنصراً في شريط واحد تحتاج طيّ المجموعات (مطبّق).

**ملاحظات:** البيانات في المعاينة عيّنة مُعلَّمة (لافتة ثابتة + عمود «عيّنة»)؛ الأرقام لاتينية (0-9) بأرقام جدولية، وهو قرار مفتوح للمستخدم؛ الأيقونات مرسومة أصلاً (شبكة 24، سماكة 1.8) فلا ترخيص خارجي.
