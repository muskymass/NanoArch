# الاتجاه B: «ورق الرسم» (Drafting Paper)

**الفكرة:** تجربة موجَّهة دافئة. شريط مراحل علوي من 6 خطوات يحوّل التبويبات العشرين إلى مسار عمل، وتحته أزرار فرعية للمرحلة الحالية، وأسفل الصفحة «السابق/التالي». ألوان ورق وحبر وطين، زوايا كبيرة، ظلال ناعمة، وكثافة مريحة.

**لوحة المزاج (فاتح):** الخلفية `#f3ede1`، السطح `#fbf8f1`، النص `#2b2218`، التمييز الافتراضي طيني `#a34326`. الداكن: بني دافئ `#1a1612`. خيارات التمييز: طيني، زيتوني، حبري، فيروزي، أصفر ترابي (كلها مجتازة AA).

**الخطوط:** عناوين Dubai (تأتي مع Windows 10/11؛ موجودة في `C:\Windows\Fonts` على هذا الجهاز) ثم Segoe UI Variable Display؛ النص Segoe UI Variable Text. بديل مضمَّن اختياري: Readex Pro أو Tajawal (SIL OFL 1.1)، نحو 100–200 كيلوبايت للوزن (تقدير لم يُقَس).

**التنقل (المراحل = المجموعات نفسها، معرّفات `data-tab` ثابتة):** 1 المدخلات (notes، sbc) · 2 المخطط (sketch، ol، bim، pr) · 3 الامتثال (rules، ov، cp، lib) · 4 الهندسة (str، mep، mx، an) · 5 الكميات والتكلفة (qto، boq، sched، ex) · 6 المخرجات (vr، dv). المدخلات السريعة تنزلق كدرج جانبي (زر «مدخلات سريعة») بدل عمود دائم؛ الخصائص بطاقة بجانب لوحة الرسم (تنزل تحتها في النوافذ الضيقة).

**التخصيص:** لغة، وضع، لون تمييز، كثافة (الافتراضي مريح)، حجم خط؛ تُحفظ وتُستعاد.

**يصلح لمن:** المالك والمقاول والمهندس غير المتفرغ للبرنامج؛ الاستخدام المتقطع؛ من يحتاج أن يعرف «ما الخطوة التالية».

**كلفة التنفيذ: عالية.** يغيّر سلوكاً: اليوم المدخلات ولوحة الرسم واللوحة اليمنى ظاهرة معاً، وهنا شاشة واحدة في كل مرة مع درج للمدخلات. يحتاج إعادة كتابة الصدفة وCSS، وتحويل أزرار `.tab` إلى مراحل وأزرار فرعية، وإعادة اختبار كل مسار يفترض وجود المدخلات والمخطط معاً (مثل `layoutApply` والمعاينة المقسومة 2D/3D).

**المخاطر:** المستخدم الخبير يخسر الرؤية المتزامنة؛ الشاشات الكبيرة تُستغل أقل (عرض أقصى 1240px)؛ ترتيب المراحل قد يوحي بتسلسل إلزامي (الأرقام موضع لا حالة إنجاز).

**ملاحظات:** بيانات عيّنة مُعلَّمة؛ أرقام لاتينية؛ أيقونات مرسومة أصلاً.
